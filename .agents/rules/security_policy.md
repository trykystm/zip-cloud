# セキュリティポリシー (Security Policy)

## 1. 環境変数とシークレット管理

- APIキー、トークン、パスワード、データベース接続情報などの機密情報は、ソースコードや設定ファイルに直接記述（ハードコーディング）しないでください。
- 機密情報は必ず `ENV['VARIABLE_NAME']` または `ENV.fetch('VARIABLE_NAME')` を経由して読み込んでください。
- 必須の環境変数が未設定の場合に早期に検知できるよう、`ENV.fetch('VARIABLE_NAME')` の使用を推奨します。

## 2. 外部入力とインジェクション対策

- 外部からの入力値をそのまま `eval`、`system`、バッククォート（`` `...` ``）に渡さないでください。
- コマンド実行が必要な場合は、配列形式で引数を渡す `system('cmd', arg1, arg2)` や `Open3` 標準ライブラリを使用してください。
- ファイルパスを扱う際は、ディレクトリトラバーサルを防ぐため `File.expand_path` 等で適切に検証してください。

## 3. 依存ライブラリの管理

- 新規Gemを追加する際は、事前にユーザーの承認を得るとともに、メンテナンス状況や既知の脆弱性がないか確認してください。
- 標準ライブラリ（`net/http`, `json`, `csv`, `uri`, `openssl` 等）で代替可能な場合は、標準ライブラリを優先してください。

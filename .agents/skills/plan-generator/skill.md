# Plan Generator スキル

## 目的
コーディング規約の基本方針「実装を開始する前に、必ず『実装計画（Plan）』を作成し、ユーザーの承認を得てください」を確実に実行します。

## 実行手順

1. **要件の整理**
   - ユーザーの要求事項・変更対象・目的を明確にします。
2. **標準ライブラリの検討**
   - 外部Gemを追加せず、Rubyの標準ライブラリで実現可能か検討します。
   - どうしても新しいGemが必要な場合は、計画内で事前にユーザーの許可を求めます。
3. **実装計画（Plan）の構成作成**
   - **作成・変更対象ファイル一覧**: `lib/` および対応する `spec/` のファイルパス
   - **クラス・メソッド設計**: 責務、引数、戻り値、例外処理方針（`StandardError` 継承クラスの指定など）
   - **テスト計画**: RSpecで検証する正常系・異常系のテストケース
   - **セキュリティ・規約確認**: 環境変数（`ENV`）の利用有無、非破壊的メソッドの採用方針
4. **承認の確認**
   - 計画をユーザーに提示し、承認を得てから実装を開始します。

# RuboCop Auto-Fix スキル

## 目的
コーディング規約に従い、タスク完了前に `rubocop -A` を実行してスタイル違反や潜在的な問題を解消します。

## 実行手順

1. **RuboCopの自動修正実行**
   - `bundle exec rubocop -A` を実行します。
2. **結果の判定**
   - `no offenses detected` となった場合は完了とします。
   - 自動修正できないOffenseが残っている場合は、対象ファイル・行番号・Cop名を確認し、手動でリファクタリングを行います。
3. **重点確認項目**
   - インデントがスペース2つになっているか
   - 1行ブロック `{ ... }` と複数行ブロック `do ... end` が適切に使い分けられているか
   - 引数なしメソッド定義の `()` が省略されているか
   - テスト（RSpec）が修正後も全てパスするか再度確認します。

# RSpec Runner スキル

## 目的
新しい機能やクラスを作成・修正した際に対応するRSpecテストを実行し、全テストのパスおよびテストカバレッジの充足を確認します。

## 実行手順

1. **対応するSpecファイルの確認**
   - `lib/foo_bar.rb` に対して `spec/foo_bar_spec.rb` が存在するか確認します。
   - 存在しない場合は新規作成します。
2. **RSpecの実行**
   - `bundle exec rspec` を実行します。
3. **失敗時の対応とギャップ修正**
   - 失敗したテストがある場合は原因を分析し、実装またはテストコードを修正します。
   - 正常系だけでなく、境界値や例外処理（`ArgumentError` 等）のテストケースが漏れていないか確認し、不足していれば追加します。

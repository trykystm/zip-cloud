# `/add-gem` ワークフロー

`Gemfile` に新しい外部ライブラリ（Gem）を追加する必要がある場合、勝手に追加せず以下のフォーマットでユーザーに許可を求めてください。

## 申請フォーマット

1. **追加したいGem名**: `gem 'xxx'`（必要に応じてバージョン制約や `group` 指定）
2. **導入理由**: 何を実現するために必要か
3. **標準ライブラリでの代替検討結果**: Ruby標準ライブラリではなぜ不十分・困難なのか
4. **セキュリティ・メンテナンス状況**: 公式リポジトリやメンテナンス状況に問題がないか

ユーザーの明示的な承認を得てから `Gemfile` を編集し、`bundle install` を実行してください。

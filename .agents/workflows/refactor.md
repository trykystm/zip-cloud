# `/refactor` ワークフロー

既存の機能（振る舞い）を変えずに、コードの美しさと保守性を高めるリファクタリングを実施します。

1. **事前テスト実行**: `bundle exec rspec` を実行し、現状のテストが全てグリーンであることを確認します。
2. **ボーイスカウトルール適用**:
   - 破壊的メソッド（`map!`, `gsub!` 等）を非破壊的メソッドに置き換えられないか確認します。
   - `rescue Exception` があれば `rescue StandardError` または具体的な例外クラスに修正します。
   - 1行ブロック `{ ... }` と複数行ブロック `do ... end`、引数なしメソッド定義の `()` 省略など、Rubyらしい簡潔な記述に整えます。
3. **RuboCop自動修正**: `bundle exec rubocop -A` を実行し、Offenseが0件であることを確認します。
4. **事後テスト実行**: 再度 `bundle exec rspec` を実行し、すべてのテストがパスすることを確認して完了報告を行います。

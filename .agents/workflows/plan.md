# `/plan` ワークフロー

コードを書き始める前に、以下の手順で実装計画を作成し、ユーザーへ提示してください。

1. **要件と背景の確認**: 達成すべきゴールを簡潔に要約します。
2. **設計方針**:
   - 追加・変更するファイル（`lib/` 配下および `spec/` 配下）
   - クラス構成・メソッドシグネチャ・責務
   - 使用するRuby標準ライブラリ（新規Gemが必要な場合はここで申請）
3. **安全性・規約チェック**:
   - 破壊的メソッドを避け、イミュータブルな処理になっているか
   - 環境変数（`ENV`）の扱いと具体的な例外クラス（`StandardError` 等）の設計
4. **テスト計画**: RSpecで検証するテストケース一覧を記載します。
5. **承認依頼**: ユーザーに「この計画で実装を進めてよろしいでしょうか？」と確認します。
